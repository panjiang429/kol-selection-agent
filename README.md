# 作品 03 · 达人圈选 Agent

AI 应用作品集 · 作品 03 · 作者：江盼（香港城市大学 BISMIS）

**技术主线：多目标冲突 → 可解释的决策。** 多维度加权评分 + 预算约束下的层级配额组队，每一项得分都能展开看公式与代入值。

## 这是什么

把「这笔预算该投给谁」从经验判断变成可复算的模型：对达人池逐人做四维加权评分（人群匹配 / 内容相关 / 性价比 CPE / 规模适配），在预算内自动组队，逐人生成建联话术，一键导出名单 CSV。权重可调，排名不是黑箱。

## 怎么跑

单文件应用：直接双击 `index.html`，或推到 GitHub 仓库开启 Pages 后用链接访问。无需安装、无后端、无外部依赖。

## 核心逻辑

- **人群匹配分**：目标人群标签与达人受众标签重合率 + 性别门槛校验；
- **内容相关分**：品类关键词在达人品类 / 风格 / 标签中的命中率；
- **性价比分**：CPE = 报价 ÷（平均播放 × 互动率），归一化为 0-100；
- **规模适配分**：按营销目标区分——品宣看粉丝量级、带货看互动率、种草看互动率 + 体量组合；
- **组队规则**：按总分降序、单笔不超过剩余预算 60%、最多 6 位，避免预算被一个头部吃光；
- **可追溯**：每个分数都可对照公式与代入值复核，入选理由写明命中标签与 CPE。

## 数据边界（重要）

内置 32 条达人档案为**虚构示例**，仅演示评分与组队算法，不对应任何真实达人，不构成商务建议。支持 CSV 导入自有名单，字段建议：
`昵称,平台,品类,粉丝数,平均播放,互动率,女性占比,年龄,报价,风格,标签`（标签用 `|` 分隔，互动率为小数如 0.058）。

粉丝真实度、互动质量、历史转化率无法从公开信息推断，入选名单必须再用平台后台或第三方监测复核。
